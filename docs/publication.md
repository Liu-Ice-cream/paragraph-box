# 0.2.5 仓库重建与发布整理

2026-10-08。使用已核验并清理过的 0.2.5 源码快照建立全新、独立的同名仓库。Git 历史从一条新的初始提交开始，不迁移旧分支、标签、提交对象、缓存或发布附件。

## 分享内容

- 作者和提交者使用 GitHub 隐私邮箱，版权署名保留公开账号。
- README 使用通用运行环境、打包、安装和更新说明。
- 默认资料和截图均为人工样例，截图没有个人资料路径或 EXIF 字段。
- 使用 MIT 许可证；Flow Launcher 需独立安装。
- Git 忽略个人配置、运行环境、日志、索引、凭据、私钥及本地备份。
- 插件 ZIP 只包含明确列出的文件；额外放入文档、样例或资源目录的文件不会自动打包，拒绝符号链接、目录联接和其他重解析点。

## 版本记录与测量

功能版本仍为 0.2.5，配置、索引与插件 ID 不变。更新记录和 0.2.1–0.2.5 验收文档作为历史资料保留，不代表新仓库有对应 Git 提交。性能 JSON 使用基线版本标识，旧测量数据不变。重新比较旧版本时，需先在本地准备相应基线源码和提交；这些提交没有包含在新仓库中。

## 验证与边界

源码快照已有 75 项 Python 检查：74 项通过、1 项因系统缺少符号链接权限跳过。打包检查验证额外私有文件不进入 ZIP、缺失必要文件时拒绝生成包，以及指向私有目录的 Windows 目录联接被拒绝。

ZIP 解压到独立目录后，通过新的 Python 进程检索人工工作样例；JSON 协议、命中正文和第 5 行出处一致，stderr 为空。

原生 Flow 主窗口、系统粘贴和编辑器精确行号的待验收项目沿用 [0.2.5 记录](verification-0.2.5.md)。本版标为早期预览版。

旧仓库由作者另行作为私有备份保留；其中的旧对象与服务器缓存未迁移到本仓库。新仓库可见性仍由作者决定。
