VS Code 使用实际可执行文件的 --reuse-window 与 --goto 参数，传递完整路径、起始行和列；参考 [VS Code 官方命令行说明](https://code.visualstudio.com/docs/configure/command-line)。这是启动请求，不承诺编辑器已完成显示。未找到编辑器时提示调整打开方式，不自动安装软件。
