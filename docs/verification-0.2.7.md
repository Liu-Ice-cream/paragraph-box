# 0.2.7 验收记录

本版让阅读面板连续浏览本次搜索返回的结果，并在复制前重新核对出处。上一条 / 下一条结果与同一文件中的前后文分开显示；结果数量仍受已保存的检索上限约束。

2026-10-12，Windows、Python 3.14.5。86 项 Python 检查中 85 项通过，1 项因系统缺少符号链接权限跳过；Windows 目录联接隔离检查通过。新增 9 项 JavaScript 回归测试全部通过，语法检查通过。

## 自动验证

- 按检索返回顺序浏览全部结果，覆盖第 5 条之后的命中；保留关键词、目录别名、行号和当前位置，首尾不循环。
- 使用受控异步响应验证快速切换、关闭后重开与重新搜索；即使旧请求不响应中止，也不能覆盖新段落。
- 复制前重新调用原文校验；失效段落清空正文并禁用打开与复制，仍可浏览其他有效结果。
- 在复制校验返回前切换、关闭、移除预览卡片或发起新搜索，不调用剪贴板写入；有效校验只复制当前段落和对应出处。
- 普通方向键、输入控件与输入法组合操作不被浏览快捷键截获；Alt + ↑ / ↓ 切换结果。

JavaScript 测试使用 Node.js 内置测试运行器和受控 DOM / HTTP 响应。它们验证应用逻辑，不代替真实浏览器布局、原生窗口或系统剪贴板验收。

## 页面验证

使用独立配置与 7 个人工 Markdown 文件，核对 1280 × 900 和 600 × 800 窗口。卡片展示 4 条，面板可到第 7 条；末条“下一条结果”禁用。Alt 方向键可切换，普通方向键不改变结果位置；Esc 关闭恢复到原卡片的阅读按钮，重开其他卡片得到对应段落。窄窗口无横向溢出，正文独立滚动，导航与底部操作可见。

面板加载后修改人工文件，复制被拒绝，正文清空并显示重新搜索入口；移走另一人工文件也拒绝复制，均可继续浏览有效结果。有效文件的复制显示成功反馈；页面没有浏览器警告或错误日志。
