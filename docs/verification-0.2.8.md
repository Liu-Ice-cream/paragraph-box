# 0.2.8 验收记录

本版新增目录快捷筛选、真实匹配与返回数量，以及可操作的无结果引导。索引的全局问题与当前检索范围分开说明。

2026-10-14，Windows、Python 3.14.5。91 项 Python 检查中 90 项通过，1 项因系统缺少符号链接权限跳过；Windows 目录联接隔离检查通过。18 项 JavaScript 界面回归测试和语法检查通过。

## 自动验证

- 快捷筛选读取已保存目录，替换已有别名前缀并保留关键词；选择全部目录只移除范围限制。无关键词时不发送索引或搜索请求，示例词保留所选范围。
- 后端统计全部匹配数量、返回数量和配置上限；正好命中上限且没有遗漏时不显示截断提示，索引警告不计作命中结果。
- 当前别名范围中的文件与段落数量单独统计，其他目录已有内容不导致空目录误报“无匹配”。全角与 Unicode 大小写别名沿用原有匹配规则，页面使用后端返回的规范别名。
- 未知别名或仅有别名时不建立索引；缺失目录、空范围、正常范围无匹配、排除规则和过大文件的事实分别返回。
- 迟到的旧范围响应不会覆盖新范围的数量、结果或引导。配置刷新失败时清除过期结果与上限提示。
- 保留连续阅读、关闭后焦点恢复、失效原文拒绝复制及迟到复制保护。

界面测试使用 Node.js 内置测试运行器与受控 DOM / HTTP 响应，验证应用行为，不代替实际布局或原生剪贴板验收。新增范围统计属于单独计时阶段，原有匹配与排名规则保持一致。

## 页面验证

使用独立人工配置，包含写作、工作、空目录、缺失目录和一个超出大小上限的人工文件；不会扫描个人资料。核对 1280 × 900 与 600 × 800 窗口，没有横向溢出。

写作范围实际匹配 7 条、返回 3 条，提示当前上限；工作范围匹配 1 条、返回 1 条，不显示截断提示。空目录与缺失目录分别显示不同的建议，未知别名不会选中“全部目录”。减少关键词保留目录并恢复结果；扩大范围保留关键词并返回其他目录中的命中。查看索引原因会展开问题列表，并把键盘焦点移到入口。阅读面板与 Esc 返回正常，页面没有浏览器警告或错误日志。

## 安装与边界

安装包沿用明确文件白名单，不含个人配置、索引、运行环境、会话文件和开发夹具。0.2.7 覆盖升级验证保留配置和索引字节、插件 ID 及原有查询结果；新解压目录的运行检查与 Flow JSON 入口通过。本地已安装副本更新至 0.2.8，配置和索引保留。

“所有目录的索引问题”来自最近一次索引报告，可能属于当前筛选之外的目录；报告原因列表最多显示 50 项。目录存在也不保证全部文件可读，页面保留跳过与访问问题提示，不推断单一原因。阅读面板仍只浏览本次返回的结果。

本次原生工具再次未取得可操作的 Flow 窗口。实际 Flow 主窗口、系统粘贴和编辑器精确定位继续待验收；自动检查与页面反馈不代替这些项目，手动确认保持 `pending`。本版仍为早期预览版。
